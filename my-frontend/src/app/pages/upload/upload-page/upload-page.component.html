How to upload files:

  1. Select the appropriate tab for your file type (Images, Videos, or Documents)
  2. Drag and drop files into the upload zone or click to browse
  3. Files will automatically be added to the processing queue
  4. Review and start processing when ready

File Limits:

  • Images: Max 50 files, 10MB each (JPEG, PNG, GIF, WebP, etc.)
  • Videos: Max 10 files, 100MB each (MP4, MOV, AVI, etc.)
  • Documents: Max 20 files, 5MB each (PDF, DOC, TXT, etc.)
